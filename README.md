# Multi-Line Insurance Policy and Claims Management System

##  About the Project

A Salesforce-based insurance management system for managing multiple insurance products and claims in a centralized platform.

### Insurance Types
-  Auto Insurance
-  Property Insurance
-  Life Insurance

###  Key Features
- Multi-line Policy Management
- Claims Management
- Automated Claim Processing
- Centralized Claims Dashboard
